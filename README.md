# PropDevelopment - Проектная работа 5 спринта

## О компании

**PropDevelopment** — это крупная строительная компания. Она входит в топ-3 застройщиков в стране и продолжает активно развиваться.

PropDevelopment предоставляет клиентам услуги, которые связаны с покупкой недвижимости и обслуживанием жилых комплексов. В основном компания работает с частными клиентами. Их можно разделить на две категории:

- **Потенциальные покупатели жилья** (клиенты)
- **Собственники**, которые приобрели жильё у компании

### IT-продукты для клиентов

1. **Онлайн-витрина** для подбора и бронирования недвижимости из фонда PropDevelopment
2. **Онлайн-тур** — приложение, которое позволяет клиентам осмотреть жильё без посещения объекта недвижимости
3. **Онлайн-сделка** — приложение, которое позволяет проводить сделки по покупке недвижимости онлайн

### IT-продукты для собственников

Мобильное приложение, которое упрощает взаимодействия с управляющей компанией:

- Оплата услуг ЖКХ
- Получение информации от управляющей компании
- Мониторинг текущего и капитального ремонта (просмотр запланированных работ и истории проведённых работ)
- Управление «Умным домом» (автоматика в жилом помещении, управление устройством запирания квартиры)

## 1. Текущее состояние архитектуры

У компании доменная структура. Каждый домен отвечает за часть бизнеса и состоит из ряда продуктовых команд. Всего в PropDevelopment четыре домена:

### Группа сервисов для продаж

Сюда входит пять приложений:
- **Витрина продаж** (монолитное приложение)
- **client-tour-app** — приложение для онлайн-тура (+ БД)
- **client-mart-app** — приложение для онлайн-сделки (+ БД)
- **client-crm-app** — система для управления клиентскими данными (+ БД)
- **client-mart-estate-app** — приложение для управления данными о недвижимости (+ БД)

#### Логика взаимодействия с пользователем

- Монолитное приложение позволяет частным клиентам осуществлять подбор и бронирование недвижимости
- Каждое бронирование может сопровождаться осмотром (оффлайн посещение или онлайн-тур)
- При бронировании клиент указывает контактные данные: ФИО, телефон, email
- Клиент может заполнить расширенную форму для онлайн-сделки
- По результатам бронирования клиент может провести онлайн-сделку через интеграцию с госорганами

### Группа сервисов ЖКУ

Отвечают за предоставление услуг собственникам:
- **Витрина** (мобильное приложение)
- **tenant-core-app** — сервис для предоставления услуг (+ БД)
- **CRM** — система управления данными о собственниках (+ БД)

### Финансы

- **accountant-service-1** — система финансового учёта (+ БД)
- **Active Directory** — служба каталогов

### Дата

Группа сервисов для обработки данных:
- **Хранилище данных** (DWH)
- **BI-система**
- **Отчётность**

## 2. Инфраструктура

- Большинство IT-продуктов развёрнуты на **собственных серверах**
- Часть продуктов развёрнуты в **гибриде** (приватное облако + облачный провайдер)
- Для временного расширения мощностей используются облачные ресурсы
- Имеется собственный **ЦОД**
- Для всех баз данных выполняется **резервное копирование**
- Доступ внешних пользователей через **межсетевой экран (firewall)**

## 4. Проблемы и потребности бизнеса

### Глобальные проблемы

#### 1. Нарушен контроль данных

- ❌ Несколько точек регистрации нового клиента без координации
- ❌ Внутренние потоки данных контролируются не системно
- ❌ Нет ограничений на доступ к данным со стороны систем обработки
- ❌ **Клиенты видят данные других клиентов в личном кабинете!**

#### 2. Проблемы с API партнёров

Системы управляющих компаний используются без единых политик безопасности:

- ❌ Контракты API содержат персональные данные
- ❌ Некоторые контракты позволяют партнёрам получать данные, к которым у них не должно быть доступа
- ❌ Партнёр одной УК может видеть/изменять данные клиентов другой УК
- ❌ Отсутствует системный контроль за передаваемыми данными

### Потребности бизнеса

Компания собирается провести **комплексный аудит безопасности** для решения следующих задач:

1. **Повысить удовлетворённость клиентов**
   - Устранить ошибки отображения чужих данных в личном кабинете

2. **Расширить направление обработки данных**
   - Реализовать новые сервисы на базе BI-, ML- и AI-технологий
   - Решить проблему управления и хранения потоков данных

3. **Отреагировать на инциденты и рыночные изменения**
   - Предотвратить утечки данных (у конкурента недавно произошла утечка)

4. **Проверить соответствие требованиям законодательства**
   - Убедиться в соответствии бизнес-процессов требованиям законодательства РФ
   - Предотвратить возможные штрафы
